# Threadlands

**Every city lives on water, farms and wild places.**

Threadlands is a planning support system for city-regions. It shows how a city's heat, floods, food and wildlife depend on the land around it, tests plans against the climate of 2050, and points to where to act first. It runs on open global data.

Live site: [threadlands.org](https://threadlands.org)

Created by Robert Bartolucci.

## What's here

- `index.html`: the website, a single self-contained page
- `src/`: the scenario model (`model2.js`), the page template and the build scripts
- `notebooks/`: the place builder and the satellite heat check, both run in Google Colab
- `data/`: place files for Milan, San Francisco and Bangkok

## Data

OpenStreetMap, ESA WorldCover 2021, Copernicus DEM GLO-30, WorldPop 2020, HydroBASINS, and Landsat 8–9 surface temperature (USGS/NASA), via Microsoft Planetary Computer.
